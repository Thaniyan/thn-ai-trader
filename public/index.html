Broker Gateway Troubleshooting & Latency Guide

Error Diagnostics Latency Optimization Connection Handshake Validator
ERROR 10004 Re-Quote / Slippage Tolerance Violation

Cause: Volatile price movements between order creation and broker server matching.

Solution: THN Trader automatically applies a 1.5-pip dynamic slippage buffer on Exness and XTB. For fast news windows, use BUY LIMIT or SELL LIMIT setups.
ERROR 10015 Invalid Price / Off Quotes

Cause: Trading session is closed (e.g. Forex over the weekend) or market spread widened during daily rollover (21:00 - 21:05 UTC).

Solution: Check the Market Status tag in the topbar. Crypto (BTCUSDT) trades 24/7, while Forex & Metals operate Monday morning through Friday evening.
ERROR 10027 Automated Trading Disabled in Client

Cause: The MT5 terminal has the "Algo Trading" button toggled off.

Solution: Click the "Algo Trading" button in MT5's top toolbar until it displays a green play icon, or use THN Trader Cloud Web Bridge which bypasses desktop limits.
ERROR 10001 Handshake Timeout / Invalid Port

Cause: Missing port :443 or firewall blocking WebSocket TCP connections.

Solution: Always append :443 to the hostname (e.g. Exness-Real14.mt5.exness.com:443).
