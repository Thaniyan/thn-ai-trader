## Verified existing architecture

- `server/intelligence.js`: constructs `THN-EVIDENCE-7` immutable evidence snapshots with symbol, interval, selected dataset hash, source refs, missing/time bounds and limitations. The existing deterministic committee is the always-available baseline.
- `server/intelligence-provider.js`: optional authenticated OpenAI adapter and local Ollama adapter, disabled in hosted runtimes via `providerAvailability`; explicitly bounded per-process request and output budgets.
- `server/intelligence-local.js`: Ollama loopback-only, installed-weight inspection, exact model tag, bounded context/timeout, fresh snapshot and provenance rejection. It cannot work from Vercel through an operator's local address.
- `public/intelligence-generation.js`: strict `THN-GENERATION-7.1` output, cited exact source-field claims, consistent snapshot ID, context and evidenceState; unverified freeform interpretation remains separate from source-backed facts.
- `public/intelligence-workspace.js`: deterministic-first fallback, optional local pilot, single research Library; generated output status only after a genuine verified model invocation.
- `public/decision-validation.js`: current BUY/SELL/WAIT, confluence, actual source reliability, historical fixed-rule evaluation and original Trade Ticket. **Never model-authoritative**.

## Product surface

1. The default Command Center always shows the current deterministic result and actual eligible research-only levels; model generation is **off** until explicitly selected/authorized.
2. A separate opt-in **AI explanation** action on the existing research details may describe: supporting evidence, contrary methods, temporal/source quality, uncertainties and missing checks. Cite each machine-verifiable claim to `THN-EVIDENCE-7` references. Bilingual EN/AR, proper RTL.
3. Never let model prose change BUY/SELL/WAIT, confidence, historical pass/fail, Entry, SL, TPs, risk sizing, currency identity, dataset selection or order permissions. Do not turn a historical strategy result into a trade probability.
4. Status must say **Generated by [verified provider/model]** only following an actual successful, validator-accepted runtime response for the current snapshot. Otherwise label clearly as deterministic, unavailable, rejected or stale. Preserve original content and history.
5. Provide a concise explainable summary and an expandable evidence/limitations panel, not a new dashboard; native/TradingView mode separation and first-fold chart remain intact.

## Safety/integration gates

- Immutable, fresh evidence context; precise instrument/interval/provider symbol/dataset hash. Reject stale, mismatched, synthetic prospective bars or cross-instrument claims before rendering.
- Reject generated prices, percentages, probabilities, performance promises, news/earnings claims not in source, untrusted prompt instructions, invalid references, unexpected fields and tool calls. Validate all structured claims against actual reference fields, do not infer financial facts from prose.
- Use the existing bounded authenticated provider abstraction, strict timeout and cancellation, limited inputs/output, context lifetime, per-session accounting and fail-closed fallback.
- Consider hosted inference **separately**: would need dedicated login/authentication, rate limiting, durable budget/spend accounting, provider choice/pricing, region, privacy/retention, secrets, logging and explicit owner approval. Local-only models require actual installed weights, resource benchmarks and proof of compatible structured responses.
- The current OpenAI path uses a less restrictive simple JSON response contract than the local strict contract. **Before any real hosted/remote invocation, unify to strict schema validation and adversarial tests**; do not assume the current path is ready for Production.
- No false claims that passing unit tests establishes model accuracy, market profitability, prediction calibration, or live data compatibility.

## Evaluation plan (zero network or cost for CI)

Use exact JSON fixtures for bullish/bearish/mixed/WAIT and EN/AR and explicitly adversarial outputs:
- Cite valid/invalid IDs, exact vs modified numeric/source values, mismatched symbol/interval/hash/snapshot, missing uncertainty, unexpected fields, conflicting evidenceState, invented risk instructions, future-bar evidence and prompt injection attempts.
- Simulate timeouts, cancellation, provider errors, token ceilings, repeated requests, dirty/stale result ordering, credentials, and context/source switches. Check that original deterministic output survives.
- Holdout labeled analyst review of **supported citations**, unsupported claims, evidence contradiction, bilingual clarity, honest uncertainty, and abstentions; report actual failure rates, not hypothetical win probability.

## P2.2 integrated lifecycle and Command Center — 2026-11-17 candidate

The Command Center's **Evidence interpretation** action opens research details
without leaving the main page. Its review delegates to the **existing** Research
Assistant; it does not introduce a second model client, provider, conversation
store, financial engine or signal policy. The original assistant remains available
for questions, saved evidence and independently authorized local runtime settings.

The projection presents the frozen symbol/timeframe, review time, method, opposing
directional hypotheses, source observations, dataset identities and uncertainty.
Upward and downward observations are labeled by thesis rather than flattening
specialist lists: a bullish observation opposing the bearish thesis must not be
misrepresented as opposing the bullish thesis. Native disclosures keep original
chart visibility and the adjacent hypothetical Trade Ticket unchanged. Source
buttons open the recorded reference and move keyboard focus; Escape restores it.

Live response admission reuses `cleanCommittee` and strict `validateGeneration`.
Unexpected model responses to deterministic requests, fabricated facts, mismatched
model identities, instrument/timeframe/hash changes and imported/unverified current
claims fail closed. Context, assumptions, language and evidence-age changes
withdraw the current projection. Failed, cancelled and pending requests do not
present a retained answer as the new response. Current-chart actions explicitly leave a saved assistant selection before reviewing
the chart; the full-review and question handoffs share that same owner boundary.
Conversation history and saved
records are preserved; they are not silently reevaluated.

The provider boundary uses a frozen private evidence copy, bounded request deadline
and independent cancellation race. A provider ignoring its abort signal cannot
keep the assistant busy indefinitely or publish a late result. Expired/deleted
conversations reject late responses and release busy state. Structured facts must
match recorded references; model prose remains explicitly unverified. No provider
was installed, connected or activated. The generated-response browser path uses
an explicitly labeled offline mock only.

### Heritage investigation

The unmodified browser suite failed locally at the BTCUSD candidate assertion.
Instrument-event diagnostics captured `candidate: null` while the old level
explanation still existed at `thn:context`; its removal was deferred to the next
animation frame. The production fix withdraws that explanation and its description
references **synchronously** on context/dataset changes; expensive full rendering
remains coalesced. It changes no candidate eligibility or financial calculation.

There is also a test synchronization defect: the positive analysis fixture applies
to BTCUSD as well as EURUSD. An assertion made after separate Playwright round
trips can race a newly completed, valid BTCUSD analysis. The regression now records
the candidate and level explanation at the actual context event and preserves the
null/absent withdrawal assertions there. It additionally waits for completed BTCUSD
research and verifies any new candidate against its instrument, timeframe, dataset
and chart. No sleeps, thresholds, timeouts, assertions or financial guards were
relaxed to prevent new valid research from appearing.
