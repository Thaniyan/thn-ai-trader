The restored THN identity is an approved direction, not complete release approval.

The existing confluence widget moves into the Decision Center rather than being
copied. Its original grade, schools, controller and source context remain owned
by the cockpit. The compact main score is withheld when original freshness and
context gates do not support a current reading. No score is recalculated.

A small adjacent Test/View test action opens the single original fixed-strategy
form or original historical results without changing the Dashboard route. Opening
it sends no evaluation request and changes no inputs. The user explicitly runs
the original evaluator after reviewing rules, costs and independent periods.
Completed results display the original passed-check fraction, never a win rate.
These tests evaluate fixed rules, not the displayed individual trade.

Untested, running, stale/changed, failed and completed states follow original
confidence/evaluation state. A changed source/context or late response cannot
validate another market. Prior matching results are retained for inspection,
while dirty/failed/running results do not display a current check fraction.
Unmatched source, stale history and gaps have separate explicit data labels;
“recent/matched” is not an assertion that contract/currency/risk gates passed.
Calibrated win probability remains unavailable and hosted generation disabled.

Native verdict refresh preserves the owned inline component and original nodes;
it must not destroy the cockpit widget when replacing native verdict markup.
There is one chart, one score, one original evaluator form and original results.
Keyboard focus returns to the original Test/View action on Escape. The hypothetical
Trade Ticket, original risk calculations, notes and immutable Library are unchanged.

All42 existing browser test files, assertions and timeouts remain unchanged. The
additional suite covers WAIT and original-risk-validated Eligible, original form
identity, no automatic run, running/dirty/failure/retry, matching check counts,
view/return focus, late response withdrawal, stale scores and EN/AR/themes at
1440/390/320. Unit regressions cover missing/mismatched source and immutable inputs.
All mandatory local/hosted release gates and same-data screenshots are required
before candidate handoff. No main merge or Production deployment is authorized.

Acceptance evidence: [real paired screenshots and verification](evidence/decision-center/README.md).

confluence owner is not duplicated. An initial persisted non-Dashboard route
