## Working product behavior

Open **Evidence interpretation** in the existing Command Center. Without navigating
to a different page, select deterministic research or explicitly authorized local
interpretation, ask a bounded research question, follow up on the same frozen
snapshot, inspect supporting/opposing observations and cited facts, inspect
uncertainty, save to the existing Library, or export a credential-free record.
The original chart, TradingView switch, decisions, hypothetical Ticket and engines
remain authoritative. No new page, financial calculation or provider route exists.
The original closed eight-field state() contract is preserved; optional UI status
uses a separate read-only researchState() projection, without credential values.

Local controls are optional progressive details. Availability never enables AI.
A token lives only in the existing request owner's memory. Explicit inventory
requires the existing allowlisted loopback, authentication, installed weights and
exact reviewed digest. Inventory is not generation or model qualification. The
mode cannot become local generative until these access checks succeed; every
actual request checks identity again. Reload defaults to deterministic with no
token. Known local credentials in questions are refused before history or network.

A model answer is accepted only through the original strict structured contract,
context/hash/version, reference/claim/role/contradiction checks, uncertainty,
instruction/numeric fabrication refusal, and product EN/AR language checks.
Structured facts may be checked; prose and model quality still require human
review. All model qualification remains **NOT_VERIFIED**. Partial, invalid, absent,
wrong-language, stale or mismatched answers cannot become current AI research.
Deterministic fallback is labeled **no model answer accepted**, not the incorrect
claim that no model was called after an attempted generation.

## One whole-request budget, one cumulative owner

The local API budget begins with the request and is shared through evidence
capture, snapshot construction, conversation, worker startup, inventory,
generation, parsing and cancellation. No stage renews12 seconds. The browser also
withdraws an over-deadline request. The isolated Node worker reuses generateLocal
and its literal loopback transport and validators; it never installs or prepares
weights. The parent owns the unchanged cumulative request/token ceilings and
one active provider call. Each worker needs parent budget admission before HTTP;
worker replacement does not reset budgets. Parent cancellation terminates even a
CPU-stalled worker. Undelivered new sessions are removed on cancellation/failure,
rather than occupying the bounded store until expiry. Termination is requested, not represented as proof that an
external Ollama process settled. A timed-out request never accepts late output.

The CLI and product reuse the same unchanged closed compact/keep-alive/thread
validator (now server/intelligence-settings.js, re-exported by pilot-report).
Only existing explicit settings reach the encoded request; encoded settings are
not claims that Ollama applied them. No environment values or budget were changed.

Timeout before a safe answer returns a fixed TIMEOUT response. Rejected model
content retains deterministic evidence with a closed failure category, without
raw provider text, exceptions, token, private prompt or false verified-AI status.
Conversation handles are omitted from exports and Library research payloads.
Imported research remains unverified; old records are never refreshed implicitly.
