## Delivered behavior

Deterministic analysis is the default. An explicitly configured, authenticated
local Ollama-compatible runtime can interpret server-created immutable evidence.
Followups retain the same snapshot and bounded server-side conversation. Context
changes invalidate it; saved/imported research is never sent for generation.
The existing six deterministic specialists are selected by the question. A single
model call synthesizes their evidence per turn; no autonomous model agents debate
or invoke tools. This is bounded interpretation, not six independent model calls.

The interface distinguishes model interpretation from deterministic specialist
results, displays local model availability/weights and validated claims, supports
EN/AR, cancellation, evidence drill-down, Library backups and explicit new evidence
conversations. Tokens and server session IDs are excluded from persisted history,
Library records and exports. The token is held in page memory and cleared by
history deletion/reload. Browser research history remains unencrypted local data.

## Local setup (owner action, not performed by this task)

No runtime, weights, paid API or provider credentials were installed or activated.
Only reuse a trusted already-installed local model after checking CPU/RAM and its
license. No automatic pulls/downloads are supported. Configure the runtime itself
with cloud functionality disabled (`OLLAMA_NO_CLOUD=1` for compatible Ollama), and
keep it bound to loopback. Do not expose its port or forward the application.

For a private local application environment, explicitly set:

```
THN_AI_ENABLED=1
THN_AI_PROVIDER=ollama
THN_AI_OLLAMA_URL=http://127.0.0.1:11434
THN_AI_MODEL=<exact trusted installed local tag>
THN_AI_AUTH_TOKEN=<random private local token>
THN_AI_MAX_REQUESTS=8
THN_AI_MAX_OUTPUT_TOKENS=256
THN_AI_TOTAL_TOKEN_CEILING=50000
THN_AI_CONTEXT_TOKENS=8192
THN_AI_TIMEOUT_MS=12000
THN_LOCAL_PAPER=0
```

Keep the token in a private local environment file outside Git; never paste it in
chat, question text or logs. Start the existing Node24 application (`npm start`)
with that environment. In AI Intelligence, enter the token in local pilot controls,
check the runtime, then explicitly choose the local generative mode. No generation
occurs on discovery or availability checks. The OpenAI fixed-destination adapter
remains optional and disabled; this task does not authorize its paid activation.

## Boundaries and limits

- Literal HTTP loopback only, port11434, fixed tags/show/chat paths. No credentials,
  redirects, alternate ports, external URLs, model registries, pull or tool APIs.
- Exact installed tag, SHA-256 weight digest, local architecture metadata, weight
  size 1MiB–2GiB; cloud names/remote metadata are rejected before chat. A malicious
  local service could lie about weights; inventory is not runtime attestation.
- Trusted operator must still verify available RAM; no model has been started by
  this task. One application model request at a time, one thread, unload after use,
  context2048–8192, output32–800 tokens, <=20 attempts and <=50000 conservative
  token reservations per application process. Restart resets these local limits;
  they are not a distributed public-service quota. Context accounting reserves
  UTF-8 bytes for messages/schema plus template headroom, not a tokenizer proof.
- Timeout<=12s, response<=64KiB, model content<=12k chars; cancellation destroys
  the local HTTP request. External runtime cancellation/unloading must be honored
  by that runtime; the app cannot guarantee immediate release of model resources.
- Eight RAM-only sessions, six turns, ten-minute expiry, <=four prior messages,
  one bounded synthesis round. No client-supplied snapshots/history/tools/models.
- Vercel and recognized hosted runtime flags, remote sockets, nonlocal Hosts and
  forwarding headers disable generation. Bearer auth and same-origin checks are
  required. Hosted financial operations and live execution remain disabled.
- Structured facts must exactly equal cited evidence fields. Snapshot hash,
  chronology, symbol, timeframe, requested roles and contradiction state must
  agree. No model arithmetic, news data, numeric prose or predictive probabilities.
  Free-form interpretation is explicitly unverified: lexical checks and a schema
  cannot prove general semantic truth. Human review remains mandatory.
