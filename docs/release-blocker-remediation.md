## Root causes and corrections

- Gold execution: GC=F is a futures proxy for XAUUSD, so the strict exact-price guard correctly rejects it. Global exposure valuation previously blocked unrelated priced reductions and produced generic close failures. Close is now target-only, bounded to existing volume, ownership protected, audited and idempotent. Unavailable price returns correlated 409 CLOSE_PRICE_UNAVAILABLE with causeCode, never a synthetic fill. Recovery inspection distinguishes priced reductions from blocked new exposure. Worker pending fills stay blocked if any legacy exposure cannot be valued. Ledger access and cancellation remain available. Existing Gold stays recorded until an acceptable exact source is available; proxy analysis is educational and cannot authorize execution.
- Gold analysis 502: the prior candidate corrected missing clamp and fragile provider/AI error paths. Structured unavailable outcomes, request correlation, WAIT classification and timeout handling remain. A provider outage is still possible and is not converted into a trading signal.
- Quote 429: refresh fan-out, duplicate requests and upstream throttling were separate contributors. Prior single-flight/cache/queue/backoff and UI pacing remain; Retry-After no longer shortens provider requests above 300 seconds. Internal request budgets and upstream retry limitations remain distinct. Bounded retries cannot guarantee provider capacity or fresh prices.
- Cross-user UI: empty arrays previously retained old selection, persisted account DTOs and delayed response bodies restored old state. Accounts are now memory-only and session-bound. Epoch checks cover headers AND parsed bodies; cancellation, identity headers, synchronous clearing, serialized session mutation and cross-tab signals prevent obsolete results. Journals/setups are identity-scoped. Rendered reports, risk tables, charts and tooltips are cleared too. Failed login revokes the old server session. Offline logout locks the client through refresh; server revocation cannot be guaranteed while offline, and the UI says request failed.
- Storage quota: saveSetup ran outside the lifecycle try/finally. Optional storage now catches denial/quota errors with an accessible warning; valid analysis remains in memory. Generation/cancel/timeout guards always release the current lifecycle and discard obsolete results.
- Release: fixed ZIP metadata, sorted committed export, exact manifest file set and per-file hashes remove timestamp variance and reject extra/tampered files. Transition helper uses known release source hashes, an approval flag, journaled atomic replacement, source backup and interrupted rollback. It retains SQLite, keys, CA and backups and refuses unknown edits and active locks. An actual HTTPS drill exposed TIME_WAIT port refusal immediately after shutdown; SO_REUSEADDR now permits stopped sockets while active listeners still prevent transition, with a regression fixture. No database schema migration or state reset is introduced.

Changed implementation: public/app.js, public/index.html, server.js, server/accountStore.js, server/marketData.js, server/paperWorker.js; local package/inventory/transition tools; browser, incident, recovery and release-tool regressions. See git show --stat for the exact reviewed file set.
