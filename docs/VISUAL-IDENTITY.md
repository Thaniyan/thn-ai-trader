## Direction and changes

The existing THN reference has useful visual qualities: ink/navy foundations,
teal accents, confident branding, clear hierarchy and restrained depth. Its
illustrated model scores, profitability wording, account values and live-data
claims are not implemented capabilities and are not copied into the product.

This pass gives the current application one visual identity:

- Complete **THN AI TRADER** naming with the existing THN mark; no new logo,
  external font service or licensed asset dependency.
- One visible wordmark at each breakpoint. Desktop keeps the brand in the
  navigation rail and uses the header for the actual workspace name. Tablet and
  phone retain the full wordmark in the header.
- Ink/navy surfaces and restrained teal/cyan depth replace the flatter blue-gray
  treatment. Shared palette tokens reach all nine views, the native chart,
  forms, tables, evidence and research components.
- Light content is paired with a permanent navy navigation rail so light mode
  retains the same THN character. Text and active-state colors are explicitly
  scoped for contrast on the rail.
- Consistent corner radii, lighter internal borders, selected-row treatment and
  typographic hierarchy. Numerical formatting and authoritative values remain
  untouched.
- A clean vector appearance control replaces the emoji while keeping the same
  theme button and handler. Its action label follows theme and language.
- Arabic headings use natural spacing and enough line height for real glyph
  bounds. Language controls change foreground/background atomically rather than
  briefly showing a low-contrast intermediate state.

## Scope

`public/visual-identity.css` owns this appearance layer.
`public/visual-identity.js` adds the localized header label, accessible brand link
name and theme icon/action label. The original route title and controls retain
their owners. `public/index.html` loads these files and corrects the wordmark.
Build/lint syntax-check the new module, and the browser runner includes a new
identity regression suite.

No server, numerical engine, record store, broker adapter, provider request,
dependency declaration, lockfile, CI assertion or financial authorization changed.
The prior chart-first and connected-watchlist workflows remain present.
